Reproduce these results

            
Every leaderboard row was executed on Kaggle compute with a pinned harness and dataset version. Run the public set yourself with the same CLI Zapier uses:

            
git clone https://github.com/zapier/AutomationBench.git
cd AutomationBench
uv sync
uv run auto-bench --model <model-id> --reasoning-effort max
